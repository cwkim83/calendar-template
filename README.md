# 일정 달력 템플릿 (calendar-template)

서버도, 가입도, 설치도 없이 **`index.html` 파일 하나**(+ 날짜 계산 `cal.js`)로 쓰는 월간·주간 일정 달력입니다.
브라우저에서 열면 바로 쓰고, 고치고 싶은 곳은 [Claude Code](https://claude.com/claude-code)에게 말로 시키면 됩니다.

> 이 달력은 「나의 AI 비서 Sancho」 강좌(https://github.com/cwkim83/my-agent-Sancho)에서 AI 비서가 일정을 대신 적어 주던 화면을, 데이터와 서버를 걷어내고 혼자 쓸 수 있게 떼어 낸 것입니다.

- **월 보기**(4~6줄, 다른 달 날짜는 흐리게, 오늘 강조, 칸이 차면 「+N개 더」 → 그 주 보기) / **주 보기**(7칸) 전환, ◀ ▶ 오늘
- 날짜 칸을 누르면 **일정 추가**, 일정을 누르면 **수정·삭제**
- **여러 날에 걸친 일정**, 시작·끝 시각, 종류(회의·출장·외근·개인, 색 구분), 장소, 메모
- 휴대폰(폭 640px 이하): 월 보기는 색 줄만 보이고, 날짜를 누르면 그 주 목록으로 넘어갑니다
- 바꿀 때마다 **자동 저장**, `JSON 내보내기 / 불러오기`, 형식이 틀린 항목은 건너뛰고 이유를 알려 줍니다
- 데이터는 서버로 가지 않습니다. 인터넷 없이도 됩니다.

## 30초 시작

1. 이 저장소를 내려받습니다 (GitHub 의 **Code → Download ZIP**, 압축을 풉니다).
2. **`index.html` 을 더블클릭**합니다 (Chrome · Edge 권장).
3. 비어 있는 달력이 열립니다. 날짜 칸을 눌러 일정을 넣어 보세요.
   먼저 구경하고 싶으면 아래쪽 **`🧪 예시 넣기`** (전부 가상의 일정)를 누르세요.
   `index.html?sample=1` 로 열면 예시를 보기만 하고 아무것도 저장하지 않습니다.
   (`?view=week` 를 덧붙이면 주 보기로 열립니다.)

## 데이터는 어디에 있나 — 반드시 읽어 주세요

입력한 내용은 **이 브라우저의 localStorage** 에만 저장됩니다 (자동 저장, 키 이름 `calendar_template_v1`).
저장되면 아래쪽에 「저장됨 14:05」처럼 표시되고, 브라우저가 저장을 막고 있으면 **빨간 경고**가 뜹니다.

- 같은 PC·같은 브라우저에서 다시 열면 그대로 보입니다.
- **다른 PC, 다른 브라우저, 시크릿 창, 브라우저 데이터 삭제 후에는 보이지 않습니다.**
- 그래서 백업과 PC 간 이동은 **`📥 JSON 내보내기`** / **`📤 JSON 불러오기`** 로 합니다.
  내보내기 파일명은 `일정달력_<날짜>.json` 이고, 불러오면 현재 일정이 파일 내용으로 **교체**됩니다(확인 창이 먼저 뜹니다).
- 이 달력에서 내보낸 파일이 아니면 불러오기를 거절하고 지금 일정은 그대로 둡니다.
  파일 안에 형식이 틀린 일정(없는 날짜, `HH:MM` 이 아닌 시각, id 없음 등)이 섞여 있으면 멈추지 않고, 그 항목만 건너뛴 뒤 **어떤 항목이 왜 건너뛰어졌는지** 위쪽에 띄웁니다.
- 중요한 일정은 가끔 JSON 으로 내보내 두세요.
- 같은 브라우저에서 `index.html` 사본을 여러 개 열면 같은 저장소를 함께 씁니다. 같은 달력을 탭 두 개로 동시에 편집하면 나중에 저장한 쪽이 이깁니다.

## 말로 고쳐 쓰기 (Claude Code)

이 폴더에서 Claude Code 를 열고 하고 싶은 일을 그대로 말하면 됩니다. 화면은 `index.html`, 날짜 계산은 `cal.js` 로 나뉘어 있어 고칠 곳을 찾기 쉽습니다.

- 「일정 종류에 '운동'을 추가하고 색은 분홍으로 해 줘.」
- 「주간 보기를 시간표(9시~18시) 모양으로 바꿔 줘.」
- 「공휴일을 빨갛게 표시해 줘. 2026년 공휴일 목록을 넣어서.」
- 「일정에 '참석자' 칸을 추가하고, 추가·수정 창에서도 입력할 수 있게 해 줘.」

고친 뒤에는 `index.html?sample=1` 로 열어 확인하면 저장된 데이터를 건드리지 않아 안전합니다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 달력 화면 (월/주 보기, 추가·수정 창, 저장·내보내기·불러오기) |
| `cal.js` | 날짜 계산과 모양 검사 (화면을 그리지 않는 순수 함수) |
| `check.mjs` | `cal.js` 가 맞게 계산하는지 보는 점검 파일. **몰라도 되고 지워도 달력은 그대로 돕니다.** (Node.js 가 있으면 `node check.mjs`) |
